# 普通入口改为模型主导：实跑与验收

源码提交：`ba08ab1a28900507a2dfb7bc301927ab320c18e5`。

## 改了什么

用户反馈的一轮普通 AI 热点研究约48分钟，包含55次命令、27次文件读取，
研究期间还安装和编译工具、修复 X 浏览器接口。安装和修复曾获授权，问题在于
它们与研究交付绑在同一流程。最终摘要没有清楚区分旧材料与近期讨论。

之前的原生能力修复主要覆盖 `intelligence` 路径，本次补齐普通自然语言入口：
模型利用 Codex 已有能力主动选择方向、读取原文、比较并判断价值；脚本作辅助。
不以初始化来源、安装依赖或修复账号连接为普通研究的前置步骤。
明确的旧命令、其他宿主、诊断、配置、来源追踪、知识库和通知实现保留。

六分钟/18次查询读取的辅助账本跨调用保持原截止时间，失败尝试也占预算。
预算用完交付已有证据，不重置计时开始另一轮。它不控制模型的思考过程，
无法强制取消原生工具，不能据此承诺完整响应始终在六分钟内结束。

## 相同普通请求的真实结果

请求：`$last30days AI圈的热点`。实际执行原生搜索/读取，未使用模拟正文。
走 `SKILL.md → codex-research.md → 原生工具 → 保存报告`。
没有调用 setup、doctor 或研究引擎，没有安装软件、读取浏览器 Cookie、
索取新 Key、修复来源、读取实现代码或发送通知。

5次查询和13次读取/点击尝试共18个操作，六批，每批预留预算。
原生检索约145.3秒；研究账本阶段354.9秒；从最初读取 Skill 至答复保存/登记
443.095秒。额外审计和归档完成总计760.245秒，两次本地审计编排错误已修正，
这些额外工作与普通研究分开计量。

[真实中文研究答复](AI圈热点-实跑.md)包含三项：

- 10月7日 Haiku 5.5 原始公告：比较实际价格表和上下文门槛，不把厂商测算当实测。
- 9月17日 Agent 资源调度论文：读实验条件，指出回放 LLM 轨迹的适用边界。
- 9月21日 ASR 方法审计论文：区分手工样本、自动编码及未发布评测资料。

三处短引用逐字匹配真实工具正文，原始日期来自原文，答复链接与本地材料核验
均通过。一个 HN 日期列表支持有限社区样本；两篇论文是近期技术发现，不能
声称它们是全球热榜。Reuters 与系统卡读取失败，作者代码、原始测量数据、
独立实验复现及 X/Reddit/YouTube/中文社区覆盖尚缺。
不公开完整网页正文；原始工具记录在本地保留哈希用于审计。

## 使用

已安装用户从首页下载约23KB小包，完整解压，双击 `Update-Windows.cmd`。
看到 `updated` 或 `already_updated` 后，打开本机 Codex 新会话，输入原来的
自然语言请求即可。首次安装用首页完整包。云端不能代替 Windows 本机执行安装。
